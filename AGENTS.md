# Instruções do projeto

Este projeto é um sistema simples de controle de estoque feito em Python.

## Tecnologias
- Python
- FastAPI
- Pytest
- Docker

## Regras
- Manter o código simples e fácil de entender.
- Não adicionar bibliotecas sem necessidade.
- Seguir as regras descritas na especificação do projeto.
- Sempre considerar os testes existentes antes de alterar o código.
- Não alterar funcionalidades sem necessidade.
- Ao criar ou alterar funcionalidades, verificar se os testes continuam funcionando.

## Estrutura
- app/: código da aplicação
- testes/: testes automatizados
- docs/: documentação
